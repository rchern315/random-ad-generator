# Random Ad Generator

A learning-focused full-stack project for building an AI-assisted ad generation platform.

## Phase 1 goals

- Learn Next.js + React fundamentals
- Use TypeScript and TSX intentionally
- Build with clear component architecture
- Introduce design-system thinking early
- Document decisions as the app grows

## Planned architecture

```text
src/
  app/
    globals.css
    layout.tsx
    page.tsx
  components/
    layout/
    ui/
    features/
      ad-generator/
  styles/
    tokens.css
```

The project will grow in small, understandable steps so each architectural decision can be explained.
